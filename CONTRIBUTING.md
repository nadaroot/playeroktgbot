# Contributing to PlayerOK Telegram Bot

Contributions and issue reports are welcome.

### How to Contribute

1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/my-feature`.
3. Ensure syntax and requirements are up to date: `python -m py_compile bot.py`.
4. Commit your changes with clear, concise commit messages.
5. Push to your branch and open a Pull Request.

### Development Guidelines

- Follow PEP 8 style conventions.
- Never commit private tokens, passwords, cookies, or session data.
- Test both local run (`python bot.py`) and container run (`docker compose up -d`).
